- Prioritized fixes: **P0 / P1 / P2**

## Free DIY first pass

1. Title present + not absurdly long (~50–60 chars)
2. Meta description present + not truncated mid-thought (~155)
3. One clear H1
4. Count missing/empty alts on content images
5. Note missing canonical / multiple H1s

Then label each finding P0 / P1 / P2.
