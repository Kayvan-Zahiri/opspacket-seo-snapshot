# Self-serve homepage SEO punch-list (public HTML)

Use this before paying anyone. Takes ~10 minutes. View-source or DevTools → Elements.

## P0 (fix before anything else)
- [ ] Title exists and is not “Home” / “Untitled”
- [ ] Exactly one H1, and it matches what the page sells
- [ ] Page returns 200 (not soft-404) for the public URL
- [ ] Not blocked by `robots.txt` / meta robots noindex if you want Google to see it

## P1
- [ ] Meta description present (roughly under ~155 characters)
- [ ] Title roughly ~50–60 characters; unique vs other pages
- [ ] Canonical points at the preferred URL
- [ ] Main content images have non-empty alt text

## P2
- [ ] No duplicate H1s
- [ ] Important pages linked from the homepage
- [ ] HTTPS works without mixed-content warnings

Sort leftovers into P0 / P1 / P2. Skip vanity scores until those are clean.
