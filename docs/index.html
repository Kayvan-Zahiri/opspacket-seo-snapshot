A small SEO punch-list that doesn’t turn into a three-week rabbit hole

Most “SEO audits” dump hundreds of warnings. Site owners then don’t know what to fix first.

What I do for a public homepage (public HTML only — no CMS login):

  1. Title — present? ~50–60 characters? Or so long SERPs will truncate?
  2. Meta description — present? Roughly under ~155 characters so it doesn’t cut mid-sentence?
  3. H1 — exactly one clear H1 that matches the page?
  4. Image alts — count images missing alt (or empty alt when the image carries meaning)
  5. Basics — canonical present or not; missing title/meta; multiple H1s

Then findings are sorted into P0 / P1 / P2 so you know what to do this week vs later. Vanity tool scores and anything that needs Search Console or a CMS login wait until after that punch-list.
