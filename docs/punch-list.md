# A small SEO punch-list that doesn’t turn into a three-week rabbit hole

Most “SEO audits” dump hundreds of warnings. Site owners then don’t know what to fix first.

Public-homepage first pass (public HTML only — no CMS login):

1. **Title** — present? ~50–60 characters?
2. **Meta description** — present? Roughly under ~155 characters?
3. **H1** — exactly one clear H1 that matches the page?
4. **Image alts** — count missing/empty alts on content images
5. **Basics** — canonical; missing title/meta; multiple H1s

Sort into **P0 / P1 / P2**. Skip vanity scores and GSC/CMS work until after that list.
